# 📝 To-Do List Application

## About the Project

The To-Do List Application is a simple, responsive task management app developed using HTML, CSS, and JavaScript. It allows users to organize daily tasks efficiently with an interactive and user-friendly interface.

## Features

* Add new tasks.
* Mark tasks as completed using checkboxes.
* Delete tasks easily.
* Save tasks using browser localStorage.
* Retain tasks after refreshing the page.
* Responsive design for desktop and mobile devices.

## Technologies Used

* **HTML5** – Structures the application.
* **CSS3** – Provides styling and responsive layout.
* **JavaScript** – Implements interactive functionality.
* **localStorage** – Stores tasks in the browser.

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Start adding and managing your tasks.
