# Elevate Labs – Responsive Landing Page

## Project Overview

This project is a clean and responsive landing page created as part of an **Elevate Labs** assignment

The landing page is designed to provide a simple introduction to Elevate Labs and its learning, internship, and career opportunities.

## Features

* Responsive header with navigation links
* Elevate Labs branding
* Hero section with heading and description
* Call-to-action button
* Responsive design for desktop and mobile screens
* Footer with social media links
* Hover effects for navigation and buttons

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Media Queries

## Tools Used

* Visual Studio Code
* Google Chrome
* Live Server Extension

## Project Structure

```text
elevate-labs-landing-page/
│

```

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The landing page will open in Google Chrome.

## Responsive Design

The website is designed to work on different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to adjust the layout for smaller screens.
